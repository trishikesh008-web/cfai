Algorithm Time Result Complexity

Linear Search

Checks every value one by one. Works on unsorted data and is simple to understand.

Best O(1) Average O(n) Worst O(n)

Binary Search

Repeatedly divides sorted data in half. It is much faster, but the data must be sorted.

Best O(1) Average O(log n) Worst O(log n)

Bubble Sort

Swaps neighboring values until the array is sorted. It is easy to learn but slow for large data.

Best O(n) Average O(n²) Worst O(n²)

Insertion Sort

Builds a sorted section step by step. It performs well when data is already almost sorted.

Best O(n) Average O(n²) Worst O(n²)

Merge Sort

Splits data, sorts each part, and merges it back. It is reliable for larger datasets.

Best O(n log n) Average O(n log n) Worst O(n log n)

Quick Sort

Uses a pivot to divide data. It is usually fast, though pivot choice affects worst case behavior.

Best O(n log n) Average O(n log n) Worst O(n²)
